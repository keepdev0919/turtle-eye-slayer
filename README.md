# 🌊 귀살대 건강 관리 (Demon Slayer Health)
**전집중 호흡 : 안구와 경추**

개발자의 거북목 예방 및 안구 건조증 방지를 위한 '귀살대' 컨셉의 헬스 케어 프로그램입니다. 맥북 전용으로 만들어졌습니다

---

## 📖 프로젝트 개요
장시간 모니터를 보며 전집중하는 개발자들을 위해, 정해진 시간마다 귀살대 대원들이 나타나 눈운동과 거북목 방지 운동 방법을 권장합니다. 

---

## ✨ 주요 기능
- **🛡️ 정기 알림**: 매 시간 자기가 지정한 시간에 전체 화면 알림 팝업. 
- **🗡️ 랜덤 캐릭터**: 탄지로, 렌고쿠, 시노부 등 12명 이상의 대원들이 무작위로 등장하여 명대사 전송(환경설정에서 커스텀 가능)
- **🖥️ 작전 본부 (Dashboard)**:
    - 알림 스케줄러의 시작/중단 제어.
    - 실시간 상태 표시 및 미리보기 기능.
    - 환경 설정 및 자동 실행 옵션 관리.
- **📥 백그라운드 상주**: 창을 닫아도 Dock(macOS)에 상주하며 임무를 계속 수행.
- **⚙️ 완전한 커스터마이징**: 사용자가 직접 대원 이미지와 대사를 추가/수정 가능.

---

## 🛠 기술 스택
- **Language**: Python 3.x
- **GUI Framework**: Tkinter
- **Image Processing**: Pillow (PIL)
- **Task Scheduling**: schedule
- **Distribution**: PyInstaller (macOS `.app` Bundle)

---

## 🚀 실행 방법 (개발자용)

### 1. 환경 설정
```bash
# 가상환경 활성화
python3 -m venv venv
source venv/bin/activate

# 필수 라이브러리 설치
pip install -r requirements.txt
```

### 2. 프로그램 실행
```bash
python3 src/dashboard.py
```
> '임무 시작' 버튼을 누르면 백그라운드 스케줄러가 가동되며, 알림 시간에 맞춰 팝업이 나타납니다.

---

## 📦 애플리케이션 빌드 (macOS)
제공된 스크립트를 사용하여 단일 `.app` 파일로 빌드할 수 있습니다.

```bash
sh scripts/build_apps.sh
```
빌드가 완료되면 루트 디렉토리에 **`귀살대 건강 관리.app`**이 생성됩니다.

---

## 📂 프로젝트 구조
```text
.
├── src/                # 소스 코드
│   ├── dashboard.py    # 메인 작전 본부 (GUI & 스케줄러 제어)
│   ├── main.py         # 백그라운드 알림 로직
│   ├── settings.py     # 대원 및 일정 관리 설정창
│   ├── popup.py        # 알림 팝업창
│   └── utils.py        # 설정 및 리소스 관리 유틸리티
├── assets/             # 대원 이미지 및 아이콘 리소스
├── data/               # 설정(config.json) 및 캐릭터 데이터(characters.json)
├── scripts/            # 빌드 및 자동화 스크립트
└── requirements.txt    # 의존성 패키지 목록
```

---

## ⚠️ 문제 해결 및 참고사항
- **"응용 프로그램을 열 수 없습니다" (macOS)**: 보안 정책상 앱이 실행되지 않을 경우 터미널에서 아래 명령어를 수행하세요.
  ```bash
  xattr -cr "귀살대 건강 관리.app"
  ```
- **백그라운드 복구**: 창을 닫아도 프로그램은 계속 실행됩니다. Dock 바에 있는 아이콘을 클릭하면 언제든지 '작전 본부'를 다시 열 수 있습니다.
